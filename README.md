# Русификация Lynk & Co

Готовые выпуски независимой русификации. Это не официальный канал обновлений Lynk & Co.

В каждом выпуске отдельно указаны версия приложения Lynk и версия русификации.

[Скачать русификацию](https://github.com/albass/lynkco-ru-updates/releases)

Для установки обновления используется тот же ключ подписи, что у предыдущих сборок нашей адаптации. APK другой адаптации может быть несовместима по подписи.

В приложении: удерживайте значок → «Русификация». Новые выпуски также предлагаются при открытии приложения.

Служебные файлы latest.json и dictionary-*.json подписаны; они используются встроенным механизмом обновлений.
